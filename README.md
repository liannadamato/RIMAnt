RIMAnt tree is a web-based tool for exploring and querying ancient musical instrument nomenclature.

Online Demo:

https://liannadamato.github.io/RIMAnt/

Author:

Lianna Flavia D'Amato

Description:

RIMAnt Tree supports the exploration and retrieval of multilingual names of ancient musical instruments through an interactive web interface. 
The nomenclature was developed by the RIMAnt Research Group (https://rimant.hypotheses.org) and published on Wikidata (https://www.wikidata.org/wiki/Q136724142).

Queries are available on Wikidata: 
https://www.wikidata.org/wiki/Wikidata:WikiProject_Ethnomusicological_descriptors_-_University_of_Turin/RIMAnt
